= Retired Ruby Database Interface

The first-party Ruby database interface, IDL compiler, generators, gems, and
development wrappers were retired during the Python migration. They are not a
supported UDB interface.

Use the installed `udb` command for database operations and the Python API for
embedding UDB. Repository development uses `mise run <task>`.

See link:python-api.md[the Python API guide] and
link:python-migration-command-map.md[the migration command map]. This file is
retained only because repository licensing metadata names its path.
