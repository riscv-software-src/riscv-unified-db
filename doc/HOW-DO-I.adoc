== Development

=== Run regression tests

To run all locally (takes a long time):

[source,bash]
--
mise run check:all
--

To list available regression tasks:

[source,bash]
--
mise tasks
--

To run a specific regression test:

[source,bash]
--
# run the Sorbet test
mise run test:ruby:sorbet
--

To run all regression tests matching a tag:

[source,bash]
--
# run the smoke group
mise run check:smoke
--

=== Add a new regression

Add a local regression as a mise task under `tools/dev/regression-tasks/`.
Add it to the appropriate aggregate task in `tools/dev/regression-aggregates.toml`.
If CI should run it, add a readable job or job step to `.github/workflows/regress.yml`.

See xref:regress-test-infrastructure.adoc[Regression test infrastructure] for more details.


=== Update Ruby gem dependencies to latest versions

To update Ruby gems to the latest available versions, run:

[source,bash]
----
./bin/chore update gems
----

Then `git add` all updated/new files and make a PR.

=== Add a new Ruby gem dependence

Add the gem in the appropriate gemspace or Gemfile (top, or one of the sub-project gems under tools/ruby-gems).

Install it:

[source,bash]
----
./bin/chore install gems # add '-t' option to avoid incrementing the container tag
----

=== Update the version of z3 used by udb

This requires docker/podman to run since it builds a portable binary using an old distro in a container.

[source,bash]
----
./bin/chore update z3
----

Check in the updates, and make sure to bump the version of the udb gem.

=== Build the container image

To build the development container image:

[source,bash]
----
./bin/chore container build
----

To force rebuild even if the container already exists:

[source,bash]
----
./bin/chore container build -f
----

=== Pull the container image

To pull the container image from the registry:

[source,bash]
----
./bin/chore container pull
----

To force pull even if the container already exists locally:

[source,bash]
----
./bin/chore container pull -f
----

=== Remove the container image

To remove the local container image:

[source,bash]
----
./bin/chore container remove
# or use the short form:
./bin/chore container rm
----

=== Generate Ruby type definitions

To generate Sorbet type definitions for all Ruby gems:

[source,bash]
----
./bin/chore gen ruby-type-def
----

To generate type definitions for a specific gem:

[source,bash]
----
./bin/chore gen ruby-type-def -g udb    # or idlc, or udb-gen
----
