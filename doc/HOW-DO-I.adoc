== Development

=== Run regression tests

To run all locally (takes a long time):

[source,bash]
--
mise run check:all
--

To list available regression tasks:

[source,bash]
--
mise tasks
--

To run a specific regression test:

[source,bash]
--
# type-check IDL for the rv64 configuration
mise run check:idl -- --config rv64
--

To run the default Python tests:

[source,bash]
--
mise run test
--

=== Add a new regression

Declare the mise task in `tools/dev/tasks.toml` and put non-trivial reusable
logic in an appropriate Python module under `tools/dev/`.
Add it to the appropriate aggregate task.
If CI should run it, add a readable job or job step to `.github/workflows/regress.yml`.

See xref:regress-test-infrastructure.adoc[Regression test infrastructure] for more details.

=== Find a repository command

Repository development commands are mise tasks:

[source,bash]
----
mise tasks
mise run <task> -- --help
----

Database queries, validation, IDL tools, authoring, generation, and rendering
use the installed `udb` command:

[source,bash]
----
uv run udb --help
uv run udb generate --help
----

=== Build the container image

To build the development container image:

[source,bash]
----
mise run container:build
----

To force rebuild even if the container already exists:

[source,bash]
----
mise run container:build -- --force
----

=== Pull the container image

To pull the container image from the registry:

[source,bash]
----
mise run container:pull
----

To force pull even if the container already exists locally:

[source,bash]
----
mise run container:pull -- --force
----

=== Remove the container image

To remove the local container image:

[source,bash]
----
mise run container:remove
----

=== Regenerate retained artifacts

To regenerate the quick developer artifacts:

[source,bash]
----
mise run gen:quick
----

To regenerate everything maintained by the repository task surface:

[source,bash]
----
mise run gen:all
----

Run `mise tasks` for narrower generation tasks. Commands removed during the
Ruby-to-Python migration are listed once in
xref:python-migration-command-map.md[the migration command map].
